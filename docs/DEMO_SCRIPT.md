# Four-minute FactoryPulse demo

All figures are **Demo / simulated data** for fictional Pragati AutoFab Pvt. Ltd., Nashik. Press **Run Demo** on Overview; Next/Previous preserve the presentation step when returning from detail screens.

| Time | Screen | Say and show |
| --- | --- | --- |
| 0:00–0:30 | **Overview** | “In ten seconds: current kW, today's kWh and cost, factory kWh per finished unit, recoverable candidate value, the ranked next action, and annualized simulated verification.” Start at the normal baseline, then advance until LC-01 appears. |
| 0:30–0:55 | **Energy Map** | Click LC-01; follow Grid → transformer → incomer → feeder → machine. Point to direct/feeder/inferred basis and unallocated energy. “LIVE means accelerated simulation.” |
| 0:55–1:15 | **LC-01 anomaly** | Show idle power between jobs. “Total plant kWh alone does not explain whether this is useful production.” |
| 1:15–1:45 | **Loss Detective** | Show actual SEC, comparable healthy median, expected kWh, residual, and evidence state. Then show counted avoidable hours versus necessary and unexplained idle. |
| 1:45–2:15 | **Operator Context** | Show the material-wait event and changed recommendation: pre-stage the next sheet batch. Explain that an operator reason must overlap energized idle; it is not treated as waste by itself. |
| 2:15–2:50 | **Opportunities** | Compare staging, auto-standby, and replacement. Show budget, payback, production and quality guardrails; select the ranked no-CAPEX LC-01 action. The percentages are illustrative assumptions. |
| 2:50–3:20 | **What-If** | Move the idle-reduction slider, then compare current/A/B/C annual kWh, ₹, and payback. Keep good-job output constant; show why replacement is not the first energy-only move. |
| 3:20–3:35 | **SenseROI** | Briefly show the current seeded **PC-01 branch-meter** recommendation. “When a shared feeder makes attribution uncertain, we ask what seven days of measurement would clarify.” This is information value, not saving. |
| 3:35–4:00 | **Verification** | Show simulated before/after SEC and idle hours, equal good-job output and quality, adjusted-baseline kWh saving, then the Decision Passport. Close: “The prototype remembers the evidence, action, and simulated outcome; field verification is the next real-world step.” |
